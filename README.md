# Career Sorter
## Collaborators 
Shahbozbek Hakimov and Emmanuel Nifakos
## Description
Sorts jobs based on occupation category and salary. Data is sourced via csv from the Bureau of Labor Statistics and is parsed using tokenization. Salaries are sorted using merge sort and quicksort; the purpose is to compare algorithm speeds. 
## Install Instructions
Fork the repo and download job salary by occupation data from the Bureau of Labor Statistics. Put the csv in the same folder as the source code and run locally using an IDE or Makefile.
